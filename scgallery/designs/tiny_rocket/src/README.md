# Summary

RISC-V Rocket Chip design (TinyConfig).
Currently has about 25,000 cells and two 64x32 memory macros.

# Source

Elaborated from [rocket-chip](https://github.com/chipsalliance/rocket-chip)
while the flow runs. Nothing is vendored: `build.sbt` resolves rocket-chip
1.2.6 from Maven Central, which is the newest release published there and the
newest that still generates Verilog with the Scala FIRRTL compiler inside
chisel3. rocket-chip past that point elaborates through firtool (CIRCT), which
none of the gallery's flows install.

This replaces a netlist that was generated by hand from rocket-chip and
contributed by Ben Keller on Jun 25 2019.

# Modifications

`src/main/scala/GenerateTinyRocket.scala` holds all of these but the last two:

- Start from the default `TinyConfig`.
- Turn the IMem and DMem sizes down to the minimum, four sets each, which is
  256 bytes of instruction cache and a 256 byte data scratchpad. This is the
  shape the 2019 netlist was built with.
- Elaborate a subsystem without the boot ROM. The ROM embeds a flattened device
  tree, which rocket-chip builds by shelling out to `dtc`, and holds nothing the
  tile needs.
- Target `RocketTile` for synthesis, which is the actual processor. This avoids
  all the system bus overhead included in the top level, and is why the
  subsystem around the tile can be trimmed down so freely.
- Pull the SRAMs out into black boxes so the gallery can map the two large ones
  onto `la_spram`. `tiny_rocket.py` generates the wrappers from the memory
  configuration FIRRTL writes out.

Outside the Chisel build:

- Added sdc timing constraints.
- Kept `LICENSE.SiFive` from
  [rocket-chip](https://github.com/chipsalliance/rocket-chip), which the Scala
  generator is derived from and points its header at. `LICENSE.Berkeley` covered
  the core RTL and `LICENSE.jtag` the debug module's Verilog, neither of which is
  vendored here any more.
